# Power Transport

One-page responsive presentation site in French. The page uses plain HTML, CSS and JavaScript; no build step is required. Open `index.html` in a browser or serve this folder with any static web server.

## Before publishing

- Add the company's confirmed phone number, email address and preferred contact method to the contact section.
- Add the names and locations of the five agencies if they should be shown publicly. The current map is intentionally illustrative and does not claim specific locations.
- Confirm the service descriptions and operational details match the company's offering.

The brand mark and Morocco map are original inline graphics. The three supplied photos are optimized WebP files in `assets/` and are used in the hero and photo gallery.
